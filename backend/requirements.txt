# System & Software Requirements for BuildBridge Backend

## Prerequisites
- Node.js >= 18.0.0
- PostgreSQL >= 15.0 (for primary data storage)
- Redis >= 7.0 (for distributed rate limiting)
- Prisma ORM (for schema and query generation)
