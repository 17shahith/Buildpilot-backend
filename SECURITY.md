# Security Policy

## Supported Versions

Only the latest release version on the `main` branch is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

We take the security of BuildPilot seriously. If you find a security vulnerability, please do NOT create a public issue. Instead, report it responsibly:

1. Email us at `security@zetaai.online`.
2. Provide a detailed description of the vulnerability, including step-by-step instructions to reproduce it, proof-of-concept (PoC) code if available, and the potential impact.
3. Allow us up to 45 days to address and patch the vulnerability before public disclosure.

Please do not publish secrets, API keys, or vulnerability details on public channels (like GitHub issues or public chat groups) before we have reviewed it.
